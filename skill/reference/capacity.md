# Measured text capacity per layout placeholder

Generated by `maintenance/measure_capacity.py` from `template.pptx`. Do not edit by hand.

Contents: 1. Method (below) · 2. Table, one row per text placeholder, layouts in template order (covers, Agenda, Kapiteltrenner, Zitat, Key Slides, Inhalt families by background, Schlussfolie).

## 1. Method

* **Method**: placeholder width/height from the layout XML minus body insets (and the bullet indent on bulleted levels); size, face, line spacing and space-after resolved through layout -> master -> txStyles.
* **Widths**: real advance widths of **Outfit** (proxy for Mark Pro, which is not licensed; Mark Pro -> Outfit Medium 500, Mark Pro Light -> Outfit Light 300) averaged over typical English copy.
* **Line height**: 1.212 x font size, measured from 46 single-line grow-to-fit placeholders in the guide itself (Mark Pro as PowerPoint laid it out).
* **Safety margin**: characters per line are cut by 10 % for Mark Pro vs Outfit width differences and kerning.
* **Grow** placeholders (spAutoFit) expand downwards; their room is measured to the next element below (or the content-area bottom), keeping ~0.04 in clear.
* `chars/line` x `lines` = `max chars`; `max words` = max chars / 6.2. `paras` = one-line bullet paragraphs that fit.
* The lint (`sgdeck.save`) and `scripts/verify_deck.py` do not use these averages: they word-wrap the real text with the same metrics, so a long word or wide capitals are caught too.
* **Table cells** (not in the table below): one line per cell at the guide's row height 0.393 in, measured against the cell width minus margins (L 0 / R 0.098 in); a cell that wraps fails - widen it with `s.table(..., col_w=...)` or shorten. Max 9 rows incl. header and total.
